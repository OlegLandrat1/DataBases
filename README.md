## Итоговый проект по дисциплине "Базы данных"

Данный репозиторий содержит скрипты для создания схем таблиц, наполнения БД исходными данными и выполнения запросов.

Целью данного проекта является закрепление теоритических основ и практических методов работы с базами данных, полученных при прохождении данной дисциплины.

Для достижения указанной цели, в рамках данного проекта решаются следующие задачи:

1. Создание таблиц БД и их наполнение при помощи скриптов
2. Написание запросов в соответствии с условиями задач

Для выполнения задач в рамках данной работы использовался универсальный opensource SQL-клиент для управления БД и работы с данными - DBeaver.
В качестве БД выбрана MySQL.

Каждая директория содержит все необходимые файлы для подготовки БД и проверки решений в SQL-клиенте DBeaver:

DB[x]_tables.sql - скрипт создания схемы таблиц БД;
DB[x]_data.sql - скрипт с данными для наполнения таблиц БД;
DB[x]_query[x].sql - скрипт запроса в соответствии с условиями задачи.
